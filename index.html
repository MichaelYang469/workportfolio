Mortgage benchmarkEvaluating agents on mortgage workflows

Built a mortgage origination benchmark at a stealth AI startup, including a custom simulation environment, 50+ agent tools, a versioned HTTP API, and an automated evaluation harness. Agents work through loan files, request and verify documents, follow up with simulated borrowers, assess preliminary product eligibility, and prepare loan-officer handoffs. The environment models delayed responses, document replacements, reminders, deadlines, and persistent changes to each loan file during a run.

Combined sourced mortgage data with synthetic bank-statement and loan-application generation and controlled mutations to test undisclosed liabilities, inconsistent income, missing transactions, and conflicting evidence across documents. Private graders inspect complete action traces, checking workflow dependencies and whether each financial claim was supported by evidence available at the time.
